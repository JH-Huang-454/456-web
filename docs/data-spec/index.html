数据规范

本页描述 npm run build:data 生成的 JSON 的字段含义。机器可读的版本是 schema/journal.schema.json —— 整合脚本每次运行都会用它校验所有记录，校验失败则构建失败。

约定​

  • 缺失与空值：数据源里没有的字段直接省略。只有"已核对、确认没有"才写 null，例如期刊的 ccf: null 表示已核对 CCF 目录且该刊不在其中。
  • 年份：对象键一律是字符串（"2025"），值里的 year 是数字。
  • 分区：中科院、新锐的 tier 是数字 1–4；JCR 的 quartile 是字符串 Q1–Q4。
  • 排名："96/127" 保留为字符串，另拆出 rankPct（0–1，越小越靠前）。
  • 原值优先：summary 之外的字段保持数据源原值；计算得到的值只放在 summary。

输出文件​

文件内容
journals-index.json列表用的精简索引（见下），首屏加载
journals/00.json … 63.json完整记录，按 id 哈希分成 64 片，点开详情时才加载
categories.json中科院、新锐、JCR 学科与 CCF 领域的计数及大类→小类关系
meta.json数据版本、总数、各数据源覆盖数
unmatched.json没能匹配上的记录，用于人工检查

顶层字段​

字段类型说明
idstring唯一标识。期刊取 ISSN；无 ISSN 时 cn:<CN号> 或 name:<规范化刊名>；会议为 conf:<缩写小写>
typejournal | conference条目类型
yearnumber最新出现的版本年份（所有数据源取最大）。注意这是数据版本年，不是会议举办年
yearsnumber[]该条目出现过的全部版本年份，升序
name / cnName / abbrstring英文名 / 中文名 / 缩写（会议必有缩写）
issn / eissn / cnstringXXXX-XXXX 大写；cn 为国内统一刊号
publisher / languagestring出版方 / 语种
wosstring[]SCIE SSCI ESCI AHCI
isReview / isOAboolean是否综述期刊 / 开放获取（来自中科院表）
introobject简介，{en, zh, source, updatedAt}；source 为 manual official openalex ai-draft
linksobjecthomepage submission dblp wos scimago；后两项由 ISSN 拼接
coverobject封面 {file, credit, source}；没有则页面使用生成的占位封面

warning 国际期刊预警​

字段说明
current是否在最新一年（2025）名单中。页面标红只看它
latestYear最近一次被预警的年份
history[]历年记录：year；2020/2021/2023 年有 level（高/中/低）；2024 起改用 reason

从未被预警的条目省略整个 warning。

jcr 影响因子与 JCR 分区（键为年份）​

字段说明
if当年影响因子
quartile仅 2022 年有的整体分区；其他年份看 categories
categories[]学科类别（最多 6 个，2023 起有）：name quartile rank rankPct

原始数据中 2020、2021 只有影响因子，2022 只有影响因子加整体分区，缺的字段不做推断。

cas 中科院分区升级版（键为年份：2021、2022、2023、2025）​

字段说明
major / majorTier / majorRank大类名称 / 分区 1–4 / 排名（仅 2025 有）
top是否 Top 期刊
warningMark该年表里的预警标注原文
minors[]小类（最多 6 个）：name cnName tier rank

没有 2024 年版：原始数据中不存在。

xr 新锐分区（键为年份，当前仅 2026）​

结构与 cas 相近，字段为 major majorCn majorTier top minors[]，另有 major2（极少数期刊有第二个大类）、warningMark（如 Under Review）。会议只有 majorTier 与 top。

ccf / ccft CCF 目录（键为年份）​

字段说明
ccf[y].levelA B C
ccf[y].field / type / dblp领域 / 推荐类别（国际学术刊物、会议等）/ dblp 网址
ccf[y].renamedTo2019 版的"合并/更名为"
ccft[y].tierT1 T2 T3（计算领域高质量科技期刊分级目录）

当前 CCF 有 2019、2022、2026 三版，CCF-T 有 2022、2025 两版。

summary 预计算汇总​

列表页的筛选与排序只读这一块。

字段说明
latestIF最新有值的影响因子
ifTrend按 meta.jcrYears（2020–2025）对齐的 IF 序列，缺失年份为 null
jcrQ / jcrCats最新有分类年份中最好的 JCR 分区 / 学科名
casTier casMajor casMinors最新中科院年份的大类分区、大类名、小类
bestCasTier最新中科院年份大类与小类中最好的分区
xrTier xrMajor xrMinors新锐 2026 的对应信息
top中科院或新锐标记为 Top
ccfLevel / ccftTier最新版 CCF / CCF-T 等级
rating综合评级，见 评价规则

sources 数据溯源​

字段说明
matchedBy每个数据源的匹配方式：issn、name（按刊名）、abbr（会议缩写）、cn（CN 号）、new（该源独有，新建条目）
files贡献过数据的原始文件

按 name 匹配的结果可信度较低：预警名单、CCF 目录、2020–2022 年 JCR 没有 ISSN，只能靠规范化刊名对应。同名但 ISSN 不同的期刊（如 HEART RHYTHM）会被判为歧义并跳过，记录在 unmatched.json。
